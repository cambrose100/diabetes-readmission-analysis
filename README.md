# Diabetes Readmission Analysis

##  Project Overview
This project analyzes hospital readmission risk among diabetic patients using Excel. The goal was to identify key factors associated with readmissions and provide insights that could support better patient management and reduce hospital utilization.

---

## Objective
To determine which factors most strongly predict hospital readmissions among diabetic patients, focusing on:
- Age
- Length of hospital stay
- Number of prior inpatient visits

---

##  Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Data Visualization (Charts)

---

##  Key Findings
- **Prior inpatient visits** showed the strongest relationship with readmission risk, with rates increasing significantly as visit count rises.
- **Length of stay** was moderately associated with higher readmission rates, peaking around 7–10 days.
- **Age** showed increasing readmission rates from younger groups but stabilized across adult populations.

---

## Project Structure
- `Diabetes_Readmission_Analysis.xlsx` → Cleaned dataset, pivot tables, and charts
- `Diabetes_Readmission_Analysis.pdf` → Summary report with key insights and conclusions

---

##  Conclusion
Prior healthcare utilization appears to be the most significant predictor of readmission risk. Patients with frequent prior visits may benefit from targeted interventions such as enhanced discharge planning and follow-up care.
